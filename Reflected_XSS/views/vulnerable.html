📋 Vulnerable Code Path

// Route: GET /vulnerable?q=…
app.get("/vulnerable", (req, res) => {
  const q = req.query.q;

  // ⚠ FLAW — raw concatenation, no encoding
  result = "You searched for: " + q;

  res.send(page.replace("{{RESULT}}", result));
});
Root cause: The query-string value q is concatenated directly into the HTML response. The browser cannot distinguish the injected markup from the real page, so any <script> tag or event-handler attribute executes with the privileges of the current origin.
