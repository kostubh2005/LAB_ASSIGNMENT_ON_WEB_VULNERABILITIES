🎯 What is Reflected XSS?

The server takes user input from the URL and echoes it straight back into the HTML response. If the input contains <script> tags or event-handler attributes, the browser treats them as real code and executes them in the victim’s session.

⚡ Root Cause

User input is concatenated directly into the HTML string — result = "You searched for: " + q — with no output encoding, so any injected markup is interpreted by the browser.

🍪 Demo Cookie

A cookie session_id=user_abc123_secret_token has been set without the HttpOnly flag, so document.cookie can read it — exactly what a cookie-stealing XSS payload exploits.
